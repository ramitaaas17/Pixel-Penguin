# Identidad visual obligatoria
Todo elemento visible dentro del videojuego Godot debe compartir un lenguaje 2D pixel-art:
mundo, personajes, UI, texto, nombres, cursores, iconos, ventanas y estados interactivos.
Conservar legibilidad en español (acentos, ñ, ¿, ¡).
Usar assets/ui/pixel_theme.tres y scenes/ui/PixelButton.tscn para la UI existente y futura.
No introducir fuentes ni paquetes gráficos externos sin proponer origen/licencia y obtener autorización.
No aplicar estilos web, blur, glassmorphism, bordes suavizados o transiciones de UI continuas.
Usar Containers y Anchors; consultar docs/UI_PIXEL_ART.md antes de cambiar resolución o tipografía.
Preservar el contenido y las funciones de la plaza. Conservar assets originales.
No crear inventario, chat u otros sistemas solo para demostrar estilos.
Verificar las pantallas afectadas en Godot y probar español y escalado entero.
